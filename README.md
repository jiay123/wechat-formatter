# 公众号排版工具

> Markdown 一键排版，写文章 → 点复制 → 粘进公众号后台，图文一次成型。

## 能干什么

写公众号的朋友都懂：在编辑器里手动调标题颜色、分段、引用框、配图对齐……一篇下来半小时没了，还容易格式乱掉。

这工具把你的 Markdown 文字一键转成公众号排版 HTML，图片自动内联进去。点一下就能粘进公众号后台。

## 解决哪些痛点

- 不用在公众号后台手动调样式，复制粘贴就发
- 图片自动内联，不用一张张后台上传
- 段落自动按手机阅读节奏排
- 自带手机预览，发之前就能看效果

## 不做什么

不联网、不上传、不碰你任何文件。图全程在你自己电脑上，零隐私风险。

## 三步用法

1. **写文章**：左边粘贴 Markdown 内容
2. **放图片**：把图存进文章同目录的 `images/` 文件夹，在想插图的地方写 `{{图}}`
3. **复制排版**：点「复制排版」→ 去公众号后台 Ctrl+V

主标题点「复制主标题」单独填顶部栏。

## 懒人通道

把文章丢给你的 AI 助手（ChatGPT/Claude/豆包都行），让它帮你截好图、放进 `images/`、写好占位符，你最后只点「复制排版」就行。

## 手机预览

首次用「手机预览」会自动下载 Chromium 组件（约百来 MB，只下一次，之后离线可用），耐心等几分钟。

## 依赖安装

```bash
pip install pillow playwright
playwright install chromium
```

## 打包成 exe

```bash
pip install pyinstaller
pyinstaller 公众号排版.spec
```

## 注意

仅支持 Windows。手机打不开，必须在电脑上运行。
